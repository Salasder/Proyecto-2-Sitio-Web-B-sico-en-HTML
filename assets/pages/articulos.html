¿Qué es HTML y para qué sirve?

HTML es un lenguaje utilizado para crear y estructurar el contenido de las páginas web.

Con HTML podemos crear títulos, párrafos, imágenes, enlaces, listas, formularios y diferentes secciones dentro de una página web.

¿Qué es CSS?

CSS es un lenguaje utilizado para darle estilo y diseño a las páginas web.

Con CSS podemos modificar colores, tamaños, fuentes, espacios, posiciones y la apariencia general de los elementos de una página.

¿Qué es JavaScript?

JavaScript permite agregar interactividad a las páginas web.
